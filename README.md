# Expense Tracker

A simple expense and income tracker built with HTML, CSS, and JavaScript.

This project is a practice project created to learn the frontend development flow — from building the UI, to handling user input, updating the DOM, storing data locally, and adding small interactive features like filters and dark mode.

## Features

- Add income and expense transactions
- Track description, amount, category, and date
- View total income, total expenses, and balance
- Filter transactions by category and type
- Delete individual transactions
- Clear all saved transactions
- Dark mode toggle
- Data persistence using localStorage

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — main app structure
- `style.css` — styling and layout
- `script.js` — logic for tracking expenses, filtering, and local storage
